MUHAMMAD AYAN SALMAN — PORTFOLIO WEBSITE

FILES
- index.html       Main website structure
- style.css        Theme, responsive layout, and animations
- script.js        Typing effect, project filters, project popups, and form behavior
- assets/profile.png  Your supplied profile photograph

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Internet connection is needed for Bootstrap, Bootstrap Icons, and Google Fonts CDNs.

CUSTOMIZE BEFORE PUBLISHING
- In index.html, replace the GitHub and LinkedIn placeholder links with your real profile URLs.
- Add your email address. The contact form currently validates and copies a message; it does not send email because no backend/email service has been connected.
- Add project screenshots, repository URLs, and live demo URLs as your projects are completed.
- Add your own CV PDF and connect the download button when your CV is ready. A CV download button has intentionally not been shown until a real CV file is provided.
- Add your personal Instagram profile URL alongside your GitHub and LinkedIn links.

TECH STACK
HTML5, CSS3, JavaScript, Bootstrap 5.3.3, Bootstrap Icons.
